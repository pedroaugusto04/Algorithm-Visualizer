# Algorithm Visualizer

A web application designed to make learning graph algorithms easier. Build your own graph and visualize algorithms running in real time

# 🛠️ How to use

## Run Code

Run your own custom algorithm and input to watch a step-by-step animation of your code executing in real time.

<img width="1911" height="862" alt="image" src="https://github.com/user-attachments/assets/fc2cc8fa-5817-4b31-8c6a-e372f10a6b42" />


## Create Structure
In 'Create Structure', you can build your own graph

You can also use the AI Prompt to easily create any graph you want using AI
